# PH-History-Game

git syntax
1. git pull origin branch-name  -> get updates from a specific branch
2. git fetch -a  -> get all of the branches of the repo
3. git status    -> check what branch are u in
4. git checkout branch-name  -> let u switch branch

git syntax on creating a branch
1. git checkout main  -. switch to main branch
2. git pull   -> pull all recent changes
3. git checkout -b new-branch-name   -> creates and jumps into your new branch
4. git push -u origin new-branch-name  -> publish your branch on github

git syntax on committing/publishing your work on github
1. git add .   -> tells the git that u are going to add smth (space before period is required bro)
2. git commit -m "message here"     -> commit/save your work
3. git push origin head      -> publish your work on github
